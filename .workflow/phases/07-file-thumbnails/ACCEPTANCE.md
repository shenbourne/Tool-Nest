## Recorded deviations and limitations

- **Thumbnail box is 38px, not 40px.** The app has no global `box-sizing` reset, so a 40px box plus the row's 4px padding and 1px borders rendered a 58px row. The box was set to 38px and `box-sizing: border-box` declared on both elements, which lands the row exactly on the `DESIGN.md` 48px step with token-only values. Recorded in the component CSS comment.
- **No reviewed screenshot.** The MCP screenshot tool refuses paths under `.scratch/` ("not within any of the configured workspace roots") and the response-attached image is not inspectable by the agent, so visual confirmation rests on the pixel-level assertions above rather than a screenshot the agent looked at.
- **Concurrent browser use.** Another tab in the same Chrome instance was in use during this session (routes changed on the agent's tabs without agent action; a page sat on `localhost:3000/audio-trim`). Every measurement after that point was made self-validating — the script asserts the route and file name inside the same call as the measurement — and the affected tab was abandoned rather than reused. The theme toggle was exercised for the dark check and restored to `system`, verified in `localStorage` and by `GET /api/user/preferences` returning `"theme":"system"`.
- **Not covered:** formats whose decode depends on codecs the browser lacks (mkv/avi are detected as video and fall back to the icon on failure — the fallback path is verified, the successful decode of those containers is not); very large PDFs (only first-page render was exercised); and the row's appearance on a 640px mobile breakpoint.
