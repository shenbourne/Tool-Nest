# Verification

1. Run `scripts/verify` after configuring the applicable commands, plus relevant integration or manual checks.
2. Record commands, exit codes, and useful evidence in the active phase `VERIFICATION.md`. `SKIP` and `NOT RUN` are not `PASS`.
3. Verify every criterion in `ACCEPTANCE.md` through observed behavior and record its evidence and status.
4. Fix failed checks and rerun the affected set. When blocked, record the blocker and next action.
5. Mark the phase complete only after required engineering and acceptance checks pass. Merge authorization is governed by the repository Git policy.
